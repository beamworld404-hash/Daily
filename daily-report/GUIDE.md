# 关注清单日报 · 出报规范（给 Daily bot）

本规范只管**排版和呈现**：监控项、数据源、取数方式一律不变。
模板：[`template.tsx`](template.tsx)；完整示例：[`examples/2026-11-12.tsx`](examples/2026-11-12.tsx)。

---

## 1. 设计原则

1. **先结论，后证据，最后审计。** 读者 30 秒内看完 ①–④ 就够了；⑤ 是证据；⑥ 只在追查时看。
2. **一个事实只出现一次。** 同一个数字最多出现在「看板/要点」和「模块表格」两处，不再在 Callout、caption、正文里反复复述。
3. **口径说明集中放。** 数据日、新鲜度、缺项统一进「数据截至」表；方法细节统一进「取数与来源」。模块的 `caption` 只写一句口径。
4. **固定位置，固定顺序。** 每天结构一样，读者靠位置找信息，不靠读文字。

## 2. 页面结构（顺序固定）

| # | 区块 | 组件 | 规则 |
|---|---|---|---|
| — | `Page.summary` | — | ≤ 120 字、≤ 3 句。句 1 收入；句 2 恐惧贪婪 + Trench；句 3 其他有变化的模块 + 覆盖缺口。 |
| ① | 看板 | `Metrics` | 固定 4 个：恐惧贪婪 → FOMO 收入 → GMGN 收入 → Trench。`detail` = `数据日 · 变化`。不加 `tone`。 |
| ② | 修订 / 异常 | `Callout tone="warning"` | **只在**有数据修订、缺项、口径变化时出现，1–2 句。没有就整块删除，不写「今日无异常」。 |
| ③ | 今日要点 | `Section` + `Rows` | 3–5 条，见 §3。 |
| ④ | 数据截至 | `Section` + `Table` | 每个数据源一行：数据源 / 数据日或窗口 / 状态。 |
| — | 目录 | `TableOfContents` | 固定 6 项，对应下方模块 id。 |
| ⑤ | 收入 | `Table` + `ColumnSeries` | id `revenue` |
| ⑤ | Trench 与链上活动 | `Columns` + 4 × `Table` | id `onchain`；Trench 分项 → 发射台 → 机器人 → 公链 |
| ⑤ | Defined 新池 | `Table` | id `defined`；名次变化与叙事都在表里 |
| ⑤ | 社区与代码 | `Rows` + `Text` | id `community`；r/Monad + rarefriends |
| ⑤ | X 关注摘要 | `Callout` + 分组 `Rows` | id `x-digest`；按主题分组 |
| ⑥ | 取数与来源 | `Checklist` + `Properties` + `Rows` + `LinkCards` | id `methods` |

> 恐惧贪婪不再单独成节：看板已给数值、分类、上一日与变化，数据日在「数据截至」表里。

## 3. 文案节奏

### 3.1 今日要点（最重要的一块）
- 3–5 条，按「对 beam 的决策价值」排序，不按数据源顺序。
- `title`：**结论式**，≤ 20 字。写「Defined 新池榜 5 席换 4 席」，不写「Defined 新池」。
- `detail`：一句话，必须带数字或名字。
- `meta`：`来源 · 数据日/窗口`。
- 没有变化的模块（如 rarefriends 无更新）不进要点，只在「数据截至」里标「无更新」。

### 3.2 句子
- 一句只说一件事，≤ 50 字为宜；段落 ≤ 3 句。
- 数字在前，解释在后：「FOMO $300.01K，↑ 3.81%」，不写「FOMO 的收入较前一日有所增加，增幅为 3.81%」。
- 「不是实时行情」「非交易建议」这类免责**每节最多一次**，放在 `caption`。
- 禁止空话：「值得关注」「持续观察」「整体来看」。

### 3.3 X 摘要
- 按主题分组，组顺序：**行业与监管 → 市场与链上 → AI 与产品 → 安全 → 工具**。空组整组删除。组名用一行 `Text`。
- 每条 `Rows`：`title` 是事件，`detail` ≤ 2 句、保留原文数字，`meta` = `@handle · 标签`。
- 多个账号说同一件事 → 合并为一条，`meta` 列出所有账号。
- 标签只用三个：**转述**（转引他人/媒体）、**截断**（接口返回不全）、**未核实**（传闻或本报未核对）。另可标「官方」。
- 组末一行 `Text`「原帖：」列链接，用 2–6 字的短名。
- **不再**给每个账号写一段「解读：……不是已核实档案」——统一由节首的标签说明承担。
- 传闻类必须带「未核实」，并在主线 Callout 里写「本报未核实」。

### 3.4 r/Monad
- 英文标题不直接当正文：`title` 写中文结论式标题，原文链接放在「原帖：」行。
- 同一作者同一主题的多帖合并，标题后注「（N 篇）」。
- 评论 RSS 未抓时，在「原帖」行末尾一句说明；不再放一列全是 `--` 的「评论数」。

## 4. 数字与日期格式

| 内容 | 格式 | 例 |
|---|---|---|
| 美元 | 一律 `formatUsd`：`$` + 两位小数 + K/M/B | `$300.01K`、`$2.95B` |
| 变化 | `↑ / ↓` + 两位小数 % | `↑ 3.81%` |
| 点数变化 | 「升/降 N 点（分）」 | `较上一日 29 降 1 点` |
| 占比 | 两位小数 % | `16.26%` |
| 计数 | 千分位 | `76,257` |
| UTC 数据日 | `UTC MM-DD`（表头/看板），`UTC YYYY-MM-DD`（数据截至表） | `UTC 11-10` |
| 北京时间 | 首次出现写「（北京时间）」，同节后续省略 | `08:34:02（北京时间）` |

- 不再使用「万 / 亿」和「原始 USD（括号全精度）」两套并行写法。
- 百分比和占比用 `pctCell` / `athShare` 计算，不手写。

---

## 5. 颜色（tone）规则

| 位置 | 用法 |
|---|---|
| `Metrics` | 不加 tone（避免看板一片红绿）。 |
| 表格变化单元格 | `pctCell`：↑ `success`；↓ `warning`；↓ 且 ≥ 20% 用 `danger`。 |
| 「数据截至」状态 | 新抓 / 无更新 = `success`；复用缓存、部分覆盖、有修订、未抓 = `warning`；请求失败 = `danger`。 |
| `Callout` | 只用两种：② 修订/异常 = `warning`；X 主线 = `info`。全页 Callout ≤ 2 个。 |

## 6. 组件用法速查

只用 `cursor/pages` 已在旧日报里验证过的组件和属性：

| 组件 | 用途 | 注意 |
|---|---|---|
| `Page` | `title` `lang="zh-Hans"` `width="column"` `summary` | 标题固定「关注清单日报 · YYYY-MM-DD」，测试版加「（下午测试）」。 |
| `Metrics` | 看板 | 恰好 4 个。 |
| `Callout` | 修订 / 主线 | `lead` ≤ 6 字。 |
| `Section` | 模块 | `caption` ≤ 1 句，不写取数过程。 |
| `Rows` | 要点、帖子、X 条目 | `title` / `detail` / `meta` 都用字符串。 |
| `Table` | 所有数字表 | 单元格可以是字符串、`{ text, tone }` 或 `<a>`；数字列 `align="end"`。 |
| `ColumnSeries` | 收入 14 日 | `format={formatUsd}`，`ceiling` 保持 500000，除非数据超过。 |
| `Columns` | Trench 5 日 | `emphasis` 指向最后一天。 |
| `Text` | 小标题行、链接行、口径行 | 当小标题用时只写「名称 · 一句汇总」。 |
| `TableOfContents` / `Checklist` / `Properties` / `LinkCards` | 目录 / 审计 | 见模板。 |

已移除：`Divider`（分组靠小标题即可）、自定义 `AthShare` 进度条（改为收入表「占 ATH」列）、自定义 `TokenNarrative` 与 32px 图标位（改为新池表「叙事」列；近期图标经常为空，空占位只增加噪音）。

## 7. 特殊情况

| 情况 | 处理 |
|---|---|
| 数据源修订了已报道的数字 | ② Callout 写「从 X 修订为 Y」+ 对今天读数的影响；图表用修订值；「数据截至」状态加「· 有修订」。 |
| 复用缓存 | 「数据截至」状态写「复用 HH:MM 缓存」；不在每节 caption 重复。 |
| 某数据源失败 / 未抓 | 模块里一行 `Text` 说明；「数据截至」标 `danger`/`warning`；`Checklist` `done: false`。不得用旧数字冒充。 |
| 模块当日无更新 | 模块内一行字（如 rarefriends），不进要点。 |
| 首次纳入的数据 | 「较上一榜/较上一日」列写「基线」，不编造变化。 |
| 下午测试版 | 标题加「（下午测试）」；② Callout 写明「不是 09:00 正式早报」并说明与早报基线的关系。 |

## 8. 出报前自查

- [ ] summary ≤ 120 字、≤ 3 句。
- [ ] 看板 4 个 KPI 顺序正确，`detail` 都带数据日。
- [ ] 要点 3–5 条，标题是结论，每条有数字或名字。
- [ ] 「数据截至」覆盖全部 7 个数据源。
- [ ] 所有美元用 `formatUsd`，所有变化用 `pctCell`。
- [ ] 每个数字都能在当次取数缓存里找到；没有估算、没有补零。
- [ ] 传闻标「未核实」，截断标「截断」。
- [ ] 全页 Callout ≤ 2 个；没有「解读：」样板段。
